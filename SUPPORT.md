# Support

## Community help

- Use GitHub Discussions for setup questions, MCP client configurations, workflow ideas, and community examples.
- Use GitHub Issues for reproducible bugs and scoped feature requests.
- Include the package version, MCP client, Node version, operating system, selected profile, sanitized arguments, and a synthetic reproduction.
- Never upload confidential documents, credentials, personal data, or unpatched vulnerability details.

## Maintainer scope

This is free, community-supported software. Maintainers may help with defects in the published source but cannot guarantee response times, custom integrations, data recovery, or compatibility with every file and MCP client.

For private security reports, follow [SECURITY.md](SECURITY.md). For commercial AI-agent integration, software development, or partnership enquiries, contact `contact@djai.academy` or visit [Siamese Cat Dev](https://www.djai.academy/siamese_cat/dev/en/).
